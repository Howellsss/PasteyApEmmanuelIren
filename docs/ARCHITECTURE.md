# Architecture

A static single-page app. Vite builds React + TypeScript into `dist/`; Vercel serves it and rewrites every path to
`index.html` so React Router handles navigation. Nothing runs on a server.

## Application shell

`src/main.tsx` mounts `App`. `src/App.tsx` holds:

- **Routes**: one page component per path, with redirects for retired addresses.
- **`PAGE_META`**: the `<title>` and meta description for each path, applied on navigation.
- **`RouteEffects`**: jumps to the top on every page change (with `behavior: 'instant'`, since the page sets
  `scroll-behavior: smooth`), and scrolls to `#hash` targets such as `/teaching#series`.

`FloatingNav` (header and phone menu) and `Footer` wrap every page.

## Data, not markup

Content that changes is kept apart from layout, as typed arrays in `src/data/`:

- `media.ts`: latest messages, books, films, music, podcast, gallery photos, the Media menu, ministry links, the
  contact email and the book store URL.
- `sermons.ts`: every full sermon on the YouTube channel, generated by `scripts/update-sermons.mjs`.

Some page-specific copy (homepage blurbs, About themes, the events list) still sits at the top of its page file as a
local array. [CONTENT.md](CONTENT.md) maps all of it.

## Design system

Defined once in `tailwind.config.js`. Use the tokens, never raw hex values in components.

| Token                     | Use                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------- |
| `ink`, `ink-2`, `surface` | Warm near-black grounds; most sections                                              |
| `line`                    | Hairlines and borders on dark grounds                                               |
| `cream`, `ash`            | Primary and secondary text                                                          |
| `navy`, `navy-2`, `mist`  | The one "feature chapter" per page: navy ground with mist body text                 |
| `brand` (#986900)         | Gold for fills, rules, large words and the homepage Invitation band                 |
| `accent` (#C08A1E)        | The lighter gold, only for small text and marks on dark, where `brand` is too faint |

Typography: `font-display` (Kenfolg) for headings, `font-sans` (Inter) for everything else. Section headings go
through `DisplayHeading` / `SectionHeader`, which pair a numbered `ChapterMarker` with a title and a gold accent phrase.

Layout widths are the `container-editorial`, `container-wide` and `container-standard` classes in `src/index.css`.

## Motion

- **`Reveal`** (`components/ui/Reveal.tsx`): fades or slides content in the first time it scrolls into view. Built
  on `useReveal` (`lib/useReveal.ts`), a small IntersectionObserver hook.
- **`MediaReveal`**: for images. The frame slides in from its side while the picture settles from a slow zoom.
- **Section-specific motion** (the Creative accordion, the About timeline, The Irens album curtain reveal, the
  photo viewer, the phone menu's staggered entrance) lives with its component, with any CSS in `src/index.css`
  under a labelled block.
- Every animation is disabled under `prefers-reduced-motion: reduce`.

## Decisions worth knowing

- **Hero sound** (`lib/heroSound.ts`): a tiny store, shared with the header's mute button through
  `useSyncExternalStore`. It tries to play with sound; if the browser refuses, it plays muted and unmutes on the
  first tap, click or key press. Scrolling away from the hero silences it.
- **Forms** (`lib/mailto.ts`): with no backend, Contact and Invite build a `mailto:` link with the filled-in
  fields. Required fields are enforced by the browser first.
- **Book covers** are positioned absolutely inside an aspect-ratio frame. Safari does not resolve a percentage
  `max-height` on a flex child of an aspect-ratio box, which made covers overflow on iPhone.
- **YouTube thumbnails** load from `i.ytimg.com` at runtime: `maxresdefault` where it exists, otherwise `hqdefault`.
- **Path alias**: `@/` maps to `src/` (see `tsconfig.app.json` and `vite.config.ts`). Prefer it over long relative paths.
